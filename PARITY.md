# PARITY: original AMC Prep app vs Pulse Med

Goal from the user: **keep Pulse Med's look, but have every real feature of the original app.**
Baseline = Pulse Med commit `45dce60` (before the OpenCode work). Status words: **MOCK** = UI with canned data, **MISSING** = no screen, **REAL** = works.
Priority: P0 = user explicitly asked, P1 = core original feature, P2 = nice to have.

Sources (read-only):
- Original UI bundle (minified): `C:\ad\amc-app\dist\assets\index-hjpHbpsQ.js`. Extracted text per screen: `docs/original-app-strings.md`.
- Original readable extension source: `C:\ad\amc-ext\src\*.js` (chat.js, bank.js, analytics.js, workspace.js, knowledge094.js, integration094.js, store.js, retrieval.js, rules.js, taxonomy.js).
- Original server: `C:\ad\amc-app\server\{oauth,api,web}.mjs`. Electron: `C:\ad\amc-app\electron\main.cjs`.
- Data: question banks are loaded by the user at runtime; never commit them.

Rules: no canned replies pretending to be AI; every AI call goes to the user's active provider; errors are shown, never faked; state persists (IndexedDB/localStorage) across restarts.

## Suggested build order
1. Server: real oauth adapter + `/api/ai/complete` + `/api/web/research` (**in progress by OpenCode**)
2. `src/lib/ai.ts` + Settings + Tutor chat (conversation list)
3. Practice Builder AI generation (batches of 10, up to 100)
4. Library + PDF import/store + real reader
5. Ask-AI popup on selected text in the reader (Ask your books, Search, Topics are dropped)
6. Mistake notebook capture, Progress, Highlights, Flashcards, Data and exports
7. Browser polish, OCR, jobs banner
After each step the orchestrator (Hermes) runs `tsc`, `vite build`, bundles `server.mjs` and reports errors.
